# 맵 원본 갱신

원본은 `Assets/SSW/Editor/Maps/MapSources.asset`에 명시한다. MapBake는 Play와 빌드 직전에 원본 의존성 해시를 확인하고 변경된 서버 맵만 저장한다. 원본과 팀원 폴더는 수정하지 않는다. 저장되지 않은 대상 프리팹이나 연결 오류가 있으면 작업을 중단하고 해당 맵을 알려 준다.

## 연결 범위

- 갱신 대상: 1, 2, 3, 6, 7, 8, 9, 12, 13, 14, 17.
- 기존 4, 5, 10, 15, 16과 로테이션 순서는 보존한다. 신규 1, 8, 12를 뒤에 추가해 총 17개다.
- 11은 현재 MapPrefab의 16과 내용이 같아 추가하지 않았다. 16은 벚꽃 원본과 별도 경로의 눈 원본이 서로 달라 기존 맵을 유지한다.
- 13은 최신 MapPrefab 원본에 연결하고 기존 지형 override를 유지한다. 사쿠라 속도 증가 1.2와 지속 0.5초를 반영한다.
- Base a443d6d에서 실제 MapPrefab 원본의 위치가 바뀐 3, 6, 14도 갱신했다.
- Map2의 현재 원본에는 주기 설정이 없어 검증된 상시 폭포 상승 22, 가속 130을 유지한다. 새 주기 설정이 생기면 무시하지 않고 연결 오류로 알린다.
- 경계 피해·반발, 스폰 두 곳, 물리 오브젝트, 서버 전용 요소와 이벤트 참조를 함께 갱신한다. 공통 카메라는 고정 크기 9다.

## 동작

MapArea가 서버에서 실제 Collider 거리를 판정해 기어 접촉, 얼음 영역 이탈, 침수, 브레스와 감속을 처리한다. 기어는 접촉당 한 번, 얼음은 진입 후 이탈했을 때만 원본 주기로 적용한다. 침수는 3초 대기 후 1초마다 Map8에서 10, Map12에서 15 피해를 준다.

MapOrbit는 원본 공전 속도와 수평 유지 설정을 사용한다. Rigidbody 이동 속도를 명시적으로 전달해 MapMotion 동기화와 MotionCast.Carry가 같은 표면 속도를 읽는다. 플레이어를 발판의 자식으로 바꾸지 않는다.

MapFlood와 MapBreath는 첫 전투 시작 시각을 공유한다. 카드 선택을 기다리는 동안 진행하지 않는다. 물은 원본 50초와 OutQuad 곡선을 사용하며 두 이동 컴포넌트가 동시에 제어하지 않는다.

MapShake의 서버 위치를 MapMotion으로 전달한다. 화산 이벤트는 MapFlash.Play에 연결하며 공유 시작 시각으로 배경 색을 계산한다. Map17의 기존 MapTempo는 유지한다.

SakuraField의 충돌 꽃잎은 화면 밖에서도 시뮬레이션한다. 접속자에서 입자가 0개로 멈추던 화면 밖 일시정지 설정을 보완했다. 맵 종료 시 입자를 비우고 효과를 맵 자식으로 정리한다.

프로토콜은 19다. 양쪽 모두 최신 빌드가 필요하다. 17개 맵을 모두 사용하기 전에는 중복하지 않으며, 소진 후에는 다시 섞되 직전 맵을 연속 선택하지 않는 기존 규칙을 유지한다.

## 검증

- `RefreshCheck.cs`: 최신 프리팹 연결, 누락 스크립트, 경계, 스폰, 물리 참조 235개 통과. 다시 베이크했을 때 변경 없음. `Logs/Stats/MapFinal.json`.
- `MapsThird`: 17개 맵 강제 로드, 각 맵 네 경계의 양쪽 플레이어 피해 136회, 고정 카메라와 같은 스폰 위치, 이전 맵 제거 확인. 이후 공전 준비 코드의 좌표 직렬화 때문에 중단된 실행이며 전체 성공으로 기록하지 않는다.
- `MapFeatures4`: 수정한 공전에서 양쪽 플레이어가 입력 없이 탑승하고 수평 상대 위치를 유지하는 검사 통과. 이후 침수 테스트가 음수 시작 시각을 주입한 준비 오류로 중단됐다.
- `MapFlood6`: 침수 대기·상승·Animator·피해와 퇴장, 브레스 예고·입자·서버 피해, 네 발판 흔들림·감속, 화산 재점멸·실제 입자 충돌의 20 피해·입자 제거 통과. 마지막 사쿠라 입자 검사에서 접속자의 화면 밖 정지가 발견돼 수정했다.
- `SakuraFixed`: 148개 통과. 양쪽 자연 꽃잎 재생, 실제 입자 접촉에 따른 속도 증가와 만료·효과 정리, 기어 최초 접촉·지속·재진입, 얼음 미진입·진입·이탈·피해·감속·재진입을 확인했다. 실제 사망 16회로 17개 맵을 중복 없이 소진했으며 이전 맵·플레이어 제거, 재스폰, 카메라 크기 9를 양쪽에서 확인했다.
- 최종 개발 빌드 `build_6202d7667dd8`: 오류 0, 경고 12. 실행은 `Maps~/Hazards.ps1 -MapRefreshOnly`이며 새 `-Run` 이름을 지정한다. `-MapResume -MapFrom 1..5`는 완료된 앞 단계를 제외하고, `-MapAreas`는 기어·얼음만, `-MapCycle`은 실제 사망 교체만 검사한다.

검증은 한 PC의 에디터 호스트와 별도 개발 빌드 접속자다. 실제 두 PC 또는 Relay 검증이 아니다. 10Hz 진단값으로 상태와 효과 계산을 비교했으며 렌더링된 픽셀을 비교하지 않았다. 원격 상대의 공전 위치는 기록된 보간 시각의 서버 발판 위치와 비교한다. 현재 프레임의 발판 그림과 원격 상대가 완전히 일치하거나 네트워크 지연이 없다는 검증은 아니다.

피해를 분리해 검사할 때만 메모리에서 위치·동결·시각을 조절하거나 다른 피해 요소를 잠시 끈다. 화산과 사쿠라는 자연 재생을 먼저 확인한 후 통제된 실제 입자 충돌을 별도로 검사한다. 각 JSON에 준비 조작과 관측값을 보존한다. 기존 4, 5, 10, 15, 16의 외부 이펙트 풀까지 수정·검증했다고 보지 않는다.
