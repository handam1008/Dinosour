# 직업 증강 실제 효과 검증

2026-09-27, Unity 6000.5.2f1, 프로토콜 21. 활성 직업 카드 54개 중 이번 잔여 검사는 42개이며, 이미 완료한 암살자 도망·살기 2개와 총잡이 10개는 기존 근거를 재사용한다. 선택 UI·수신·리스폰 616개 결과를 실제 효과 증거로 대신하지 않는다.

## 수정

- 마술사 응급 마술·미러 카드·조커 카드의 서버 소비 시각을 접속자의 쿨타임 HUD에 전달한다. IMagicClock으로 컨트롤러와 네트워크 시계를 분리했다. 원래의 게임 시간 기준을 유지하며 느린 시간 배율에서도 양쪽 표시가 같은 기준을 사용한다. 조커는 획득·재활성화 뒤 15초 충전한다.
- 암살자 살기·전술적 변화의 원본 VFX 프리팹을 각 화면에서 생성하고 서버 활성 상태가 끝나거나 플레이어가 사라질 때 정리한다. 원본 반경·표시 시간·재질은 유지한다. 생성 여부 검사이며 화면의 모든 픽셀을 대조한 검사가 아니다.
- NetworkVariable 구성이 바뀌어 프로토콜을 20에서 21로 올렸다. 양쪽 모두 같은 새 빌드가 필요하다.

## 실행 근거

실행 소스의 기반 SHA는 `383361f8c1d5e9565cb5a313cf70429cf3177cb8`이며 당시 미커밋 런타임 변경의 SHA256은 각 실행의 Source.json에 있다. 개발 빌드는 `build_606be742ea6c`, `Builds/Effects/Game.exe`다. 이후 Base `e7543f1edcf9afb119d0a81b25bd0db254334d8e`의 BuffHealth 기본 체력 보너스 변경을 병합했으며, 이 직업 검사 경로는 바뀌지 않았다.

CoinEffects의 첫 회복 준비는 SetMax(1000)가 BuffHealth 갱신에서 원래 최대 체력으로 돌아오는 문제였다. 실제 최대 체력의 20%에서 시작하도록 준비만 수정했고, 회복량과 최대 체력 제한을 함께 검증했다. 제품 회복 코드는 이 문제 때문에 변경하지 않았다. 4444 자가 피해 검사는 임시 플레이어의 기본 체력만 높여 예상 피해를 직접 확인했다.

BladeEffects의 피해·상태·거리 검사는 임시 평지와 배치·방향을 제어했다. CoinEffects의 ID30 확률 상한 단계 사이에서만 777 만료를 앞당겼으며, 단일 777 효과의 15초 종료와 일반 강화 효과의 10초 종료는 자연 시간으로 기다렸다. MagicEffects는 카드 넉백과 추가 정밀 조제 투사체를 제어해 개별 효과를 분리했다. 귀환·마녀 반사·분산 투사체의 전체 비행은 기존 CombatSpecialFinal01/02·Peer23 근거를 재사용한다.

모든 새 멀티 실행은 한 PC의 에디터 호스트와 별도 Windows 접속자 프로세스에 양방향 지연 60ms·지터 10ms를 설정했다. 실제 두 PC 또는 UGS Relay 검사가 아니며 모든 증강 조합·모든 네트워크 상태의 무결함을 보장하지 않는다. EffectsNetwork의 검은 캡처 이미지는 외형 검증 근거로 쓰지 않는다.

각 실행의 Cleanup.json에서 자체 실행한 접속자 종료와 원래 Crate 씬 복귀, dirty=false·playing=false를 확인했다. 사용자의 기존 변경 5개는 `Logs/Integration/BeforeEffectsMerge/Files.json`에서 이전 백업과 SHA256 일치를 확인했다.

## 기존 근거와 보존 항목

- 도망 46·살기 49의 실제 수치·입력·종료·대기 검사는 `EffectsFirst`를 재사용한다. 해당 실행의 문어의 심장 HP 3 결과는 현재 HP 10 프리팹의 증거로 쓰지 않는다.
- 총잡이 10개와 공용 효과는 `Common~/README.md`의 Relay26F 등 완료 근거를 재사용한다. 기존 근거에 현재 SHA를 소급하지 않는다.
- 주머니 카드는 삭제 상태이며 ID 85는 빈 예약 슬롯이다. 기본 주머니 교환은 PocketBase의 13개 입력 검사와 13개 재현 검사를 유지한다.
- 문어의 심장은 최신 프리팹 HP 10을 보존하고 설명 HP 3과의 차이는 기존 사용자 결정 대기 상태를 유지한다.
- 병합된 Base는 BuffHealth의 다재다능 HP 기본값만 0.05로 바꿨다. 기존 Network Player 프리팹의 명시값 0.1과 원본 AJH 컨트롤러의 0.1은 그대로다. 이번 작업에서 프리팹 밸런스를 임의로 바꾸지 않았다.

재실행은 `Maps~/Hazards.ps1 -Run <새이름> -EffectFile BladeEffects`, `-EffectFile MagicEffects`, `-EffectFile CoinEffects`를 사용한다. 도박사 보완 항목만 실행하려면 `-EffectFile CoinEffects -EffectFilter '22:drain,26,28:heal,28:jackpot'`를 지정한다. 모두 프로토콜 21 개발 빌드를 `-Build`로 전달한다. 기존 EffectsOnly는 과거 HP 3 준비를 포함하므로 현재 보존된 HP 10 확인용으로 실행하지 않는다.
