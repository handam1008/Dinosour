재현한 문제와 수정

- 수정 전 지연 변동 검사 Before02에서 정상 발사 10회 중 승인 연결은 8회였고, 같은 공격의 누름·놓음이 거절됐다. 접속자는 입력 시각, 서버는 수신 시각부터 쿨타임을 계산했던 것이 원인이다. 이제 양쪽이 같은 입력 틱으로 재사용 시간을 계산한다. 발사 명령은 순서대로 처리하고 해당 이동 입력도 함께 전달한다.
- 서버의 현재 위치에서 카드를 만들면 이동 중 발사 위치가 접속자 화면과 달랐다. 서버가 검증한 입력 틱별 위치를 보관하고 그 위치에서 발사한다. 정지 중 생략하는 입력도 위치 기록을 남긴다.
- 화면에 보인 상대와 서버의 현재 상대 위치가 달라 가까운 공격이 빗나갔다. ImpactBefore01에서는 상대가 점프할 때 접속자가 본 위치를 통과해도 피해가 없었다. 상대가 실제로 표시된 시각과 서버의 위치 이력을 사용해 이동 캡슐 충돌을 판정한다. 보정 범위는 서버가 측정한 RTT에 따라 제한한다. 지형과 상대 중 먼저 부딪힌 곳만 처리하고, 기존 트리거와 중복 피해가 나지 않게 했다.

- 회수 카드가 벽을 맞은 뒤 종료 처리되거나, 이미 없어진 지형에 표시가 고정되는 경로를 보완했다. 반환할 때는 방향 변경과 현재 위치 판정을 사용한다.
- 중간 수정본에서 로딩 후 물리 시계가 수 초 밀려 반환 카드가 접속자 화면에서 멈추는 문제를 발견했다. 네트워크 시각과 물리 시각의 오프셋을 매 프레임 보정하고, 각 물리 단계의 시각은 단조 증가하도록 수정했다.
- 카드 숫자·문양은 서버가 전달한 난수 시드와 입력 틱을 공유한다. 승인 응답에는 추첨 시작 틱도 포함해 쿨타임 경계에서 예측하지 못한 승인도 복구한다.
