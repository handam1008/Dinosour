# 경사 점프와 칼 순간이동

2026-09-26. Base ef7a9e3에서 작업. Unity 6000.5.2f1, Unity CLI 사용.

## 수정

- MotionCast가 축소한 별도 캡슐 대신 플레이어의 실제 Collider2D로 이동·접촉을 검사한다. 시작부터 접촉한 경우에도 실제 접촉 법선을 사용한다.
- 경사각에 맞는 여유 거리를 유지하고, 수치 오차만으로 대시 속도를 없애지 않는다.
- 걸을 수 있는 경사에서 겹침을 해소할 때 올라가는 속도를 새로 만들지 않는다. 이동 발판의 표면 속도와 실제 상승 중인 점프는 유지한다.
- 암살자는 보간된 Transform 대신 칼 Rigidbody2D의 실제 위치를 목적지로 사용한다. 중간 경로를 가로·세로로 이동시키며 막는 기존 Clip 계산을 제거했다.
- 박힌 칼은 접촉 법선과 플레이어 크기를 이용해 같은 면의 빈 공간에 배치한다. 목적지에 캐릭터가 들어갈 수 없으면 순간이동을 취소한다. 공중 칼의 기존 전방 추진은 유지한다.
- 이동 계산이 다른 이전 버전과 연결되지 않도록 Protocol을 12로 올렸다.

## 확인한 재현

- 수정 전 45도 경사에서 가만히 있는 플레이어가 약 1.47만큼 미끄러졌다. 기존 JumpChecks도 30도 착지에서 실패했다.
- 경사 위쪽으로 움직이며 접촉이 0.02 겹친 경우 점프 입력의 상승 속도가 약 2.91로 끝났다. 접촉 보정으로 생긴 상승을 실제 점프로 취급해 입력이 버려지는 경우였다.
- 중간에 벽이 있는 목적지에 기존 경로 이동 계산을 적용하면 목표에서 2 이상 떨어진 곳에 멈추는 것을 재현했다.

## 남은 검증

- 위 Relay 검사는 마지막 겹침 복구 속도 수정 전 개발 빌드의 결과다. 해당 최종 수정은 재컴파일과 JumpChecks·Placement·Water에서 검증했다.
- Relay1의 지연 조건은 테스트용 순간이동 직후 동기화를 기다리지 않은 상태에서 점프가 누락됐다. 테스트는 양쪽 Epoch와 착지를 확인한 뒤 입력하도록 보완했고 Relay2에서 통과했다.
- Relay2의 세로 벽 검사에서 칼이 박힌 상태를 얻지 못했다. 벽 검사에 사용한 공중 스폰 뒤 대기 시간을 줄이고 위치·칼 샘플을 기록하도록 보완했다. 벽과 비행 중 칼의 최종 Relay 검사는 아직 완료되지 않았다.
- 재빌드 build_6638e3ddc0f4는 Unity BuildPipeline의 전처리 뒤 멈췄다. editor_status도 30초 시간 초과가 났고 사용자에게 확인창 여부를 문의했다. 컴퓨터 유즈는 사용하지 않았다.
- Builds/Play는 이번 변경이 반영된 빌드가 아니다. 빌드 완료 후 양쪽 PC를 같은 Protocol 12 버전으로 실행해야 한다.
- 별도 두 PC 환경은 이번에 검증하지 않았다.
