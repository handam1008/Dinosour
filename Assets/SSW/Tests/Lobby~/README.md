# 대기방 참가자와 직업 미리보기

프로젝트 루트에서 동일 소스의 MainMenu, SuperUltraLegendScene을 포함하는 Windows 개발 빌드를 만든 뒤 `Verify.ps1 -Run 새이름`을 실행한다. 기본 빌드는 `Builds/Lobby28/Game.exe`다. 이미 확인한 커마 검사를 제외하려면 `-SkipPreview`를 사용한다.

검사는 별도 인증 프로필과 비공개 UGS 방을 사용한다. 실제 이름과 직업 표시, 방장 정렬, 방장 전용 추방 버튼, 참가자의 직접 추방 호출 거절, 자기 자신과 없는 참가자 추방 거절, UGS 참가자 제거, Relay 종료, 추방 안내, 방 유지, 재접속, 방장 역할 반전을 확인한다. 종료 시 테스트 플레이어와 방을 정리하고 원래 씬과 직업 설정을 복구한다.

`Preview.cs`는 기존 커마 버튼으로 24종의 스킨을 저장한 뒤 직업창에서 프레임, 표시 이미지, 애니메이션, 모자를 검사한다. 여섯 직업을 선택해 스킨 유지와 모자 변경을 확인하고 원래 커마 설정을 복구한다.
