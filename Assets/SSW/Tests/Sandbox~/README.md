샌드박스 직업 검증

- 메인 메뉴 → 샌드박스에서 멀티와 같은 플레이어 프리팹을 사용한다. Relay 로그인 없이 로컬 전투만 실행한다.
- 기존 맵 선택, P 공용 증강, O 공용→직업 증강, R 초기화, Esc 일시정지를 유지한다.
- 공격은 마우스 왼쪽, 직업 스킬은 기존 왼쪽 Shift, 칼잽이 패링은 E다.
- 사망·낙하 후 지정 스폰 위치로 돌아가며 증강과 누적 진행도를 유지한다. 더미는 자동 회복하고 사망 시 다시 생성된다.

Unity CLI 검증

1. `Begin.cs`로 원래 직업을 보관하고 Play Mode를 시작한다. 준비 완료 후 `Open.cs`로 실제 메뉴의 샌드박스 버튼을 실행한다.
2. `Verify.cs`: 여섯 직업 이동·점프·공격·무기, 칼잽이 대시/패링, 암살자 단검/이동, 실제 카드 UI의 공용→직업 선택, 증강 유지, 더미 부활, 메뉴 복귀. 83개 확인 통과.
3. 마녀로 샌드박스 진입 후 `Cases.cs`: 일시정지 중 포션 제조·은신·무적·암전·물리 시각 정지, 재개 후 만료, 더미 부활 시 단검 유지, R 초기화 정리. 9개 확인 통과.
4. `Maps.cs`: 기본/점프패드/텔레포트/사라지는 발판 씬, 다리/그네/바람 프리팹 맵의 직업 유지·스폰·기믹·초기화. 21개 확인 통과.
5. 칼잽이 샌드박스에서 `Input.cs`: 실제 입력 이벤트와 더미 회복·일시정지·콜백 정리. 9개 확인 통과.
6. `Relay.ps1 -Run <새 이름> -EditorClient`: 개발 빌드 호스트와 에디터 접속자를 실제 UGS 비공개 Relay 방에 연결한다. 양쪽 근접 공격, 접속자 패링·회복·증강 대시, 양쪽 칼 표시, 종료·방 해제를 확인한다. 11개 확인 통과.
7. Play Mode를 종료하고 `Restore.cs`로 원래 선택 직업을 복원한다.

결과는 `Logs/Sandbox`와 `Logs/Relay/SwordSandbox24b`에 저장했다. Relay 검증은 같은 PC의 서로 다른 프로세스/인증 프로필로 수행했으며, 서로 다른 실물 PC 테스트는 포함하지 않는다.

`Setup.cs`와 `Weapon.cs`는 Unity 에디터에서 씬 참조 및 무기 방향을 설정하는 작성용 스크립트다. 연결 상태는 `unity status --format json`, 실행은 `unity command eval_file --file <절대 경로> --project-path D:/unity_project/Mushrooms --caller plugin --skill unity-cli --format json`으로 확인한다.
