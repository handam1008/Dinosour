# 직업·메뉴 검증

2026-09-24, Unity 6000.5.2f1, Base 7aeed1b 기준.

## 적용

- 첫 메뉴의 리더보드 버튼에서 순위·닉네임·승점 화면을 열고 뒤로 돌아온다. 조회·저장 기능은 연결하지 않았다.
- 마녀·마술사에 더해 총잡이·도박사·암살자·칼잽이의 서버 공격과 직업 증강을 연결했다.
- 직업별 카드 수는 마녀 6, 마술사 10, 총잡이 10, 도박사 10, 암살자 11, 칼잽이 4다. 공용 6장을 포함해 57장이다.
- 탄환·코인·단검은 기존 투사체 예측·서버 인계 경로를 공유한다. 돌진도 소유자 예측 후 서버 상태로 보정한다.
- 축소 복귀와 단검 순간이동의 지형 관통을 수정했다. 패링은 새 탄환을 반사하며, 증강에 따라 회복과 다음 돌진 강화를 적용한다.
- 포션 시각 효과의 예외가 충돌 처리와 투사체 제거를 중단시키지 않도록 격리했다.

## 확인한 동작

- 에디터 Play에서 리더보드 열기·뒤로 가기와 TMP 텍스트 넘침 검증.
- 호스트·접속자 실행본에서 총·코인·근접 공격의 체력 일치, 강화탄 진행도, 빙결, 축소, 은신, 패링 회복·반사 검증.
- 축소 종료 후 같은 발판에 정상 복귀. 돌진은 80ms 전송 지연과 5ms 지터 조건에서 소유자 이동 예측 확인.
- 도박사 확정 잭팟의 체력·최대 체력·이동속도·공격 배율과 진행도 초기화 검증.
- 라운드 재생성 후 보유 카드와 퀘스트 진행도 유지. 라운드는 카드 선택 없이 진행하고, 세트 패자만 공용 다음 직업 카드를 선택하는 흐름 검증.
- 실제 Unity Services 비공개 방에서 개발 빌드 호스트와 에디터 접속자를 연결. 별도 인증, 암살자 타격·은신·암전·단검 인계·안전한 회수, 퇴장·세션 해제 9개 검증 통과.
- 포션 다중 투척·반사·잔류 효과를 포함한 15초 기록에서 예외·연결 끊김 없음. 양쪽 프레임 p95 16.67ms, 최대 호스트 32.10ms·접속자 24.07ms. 같은 PC에서 측정한 값이다.
- 모든 직업의 카드 후보 수, 신규 어댑터와 투사체·시야 마스크 연결, 플레이어 누락 스크립트 없음 확인.

## 재실행

연결된 에디터는 MainMenu를 연 Edit 모드여야 한다. 개발 빌드는 Builds/Local/Game.exe를 사용한다.

```powershell
& 'Assets/SSW/Tests/Jobs~/Start.ps1' -HostJob Gunner -ClientJob Swordsman -Run NewRun -Port 7795
& 'Assets/SSW/Tests/Jobs~/Relay.ps1' -Run NewRelay -HostJob Gambler -ClientJob Assassin -EditorClient
```

Start.ps1은 실행본을 유지한다. 종료할 때 Probe.ps1을 불러와 각 peer에 quit 명령을 보낸다. Relay.ps1은 세션을 나간 뒤 자신이 시작한 실행본과 Play 모드를 종료한다.

원시 기록과 화면은 Logs/Jobs24, Logs/Relay/Jobs24에 보관했다. 사용자 보고의 포션 서버 이상 증상 자체는 이번 환경에서 재현되지 않았다. 다른 PC 실환경은 연결 도구가 응답하지 않아 확인하지 못했다. 구버전과 통신 구조가 달라 양쪽 모두 새 버전이 필요하다.
