이번 대상은 KDH 최신 원본의 2·11·15·16번이다. 다른 팀원 폴더는 읽기만 한다.

- Map02: 10초 대기 후 5초 상승, 원본 힘 5.5와 파티클 두 개를 같은 서버 시계로 연결한다.
- Map11: 로테이션에 추가한다. 발판·핀·줄 3개, 질량 25, 사쿠라 지속 0.5초·속도 1.2를 원본에서 읽는다.
- Map15: 기존 LiftZone 대신 작은 폭포의 원본 힘 5를 양쪽 예측 이동에 연결한다.
- Map16: 발판·핀·줄 11개, 질량 25·줄 길이 6을 원본에서 읽고 이전 사쿠라와 줄 길이 오버라이드를 제거한다.

맵 루트·GUID·NetworkObject는 유지한다. 요청한 네 맵의 이전 Assets/MapPrefab 원본을 KDH 원본으로 바꿀 때만 기존 중첩 프리팹 오버라이드를 초기화하고 네트워크 연결을 다시 구성한다. Map02의 루트 스폰 마커는 유지한다. 경계 피해 5·반발 20은 요청된 원본 수치를 사용한다. 다른 맵의 경계 튜닝은 그대로 보존한다.

연결된 에디터에서 컴파일 후 Setup.cs, Check.cs 순으로 eval_file을 실행한다. Setup은 Logs/MapPatch/Before에 이전 자산을 백업하고 네 맵만 갱신한다. MapBake 전역 버전은 6을 유지한다. 검증 도중 MapBake.Scope 세션 값으로 Play·빌드 자동 갱신도 네 맵으로 제한한다. 검증·빌드가 끝나면 Cleanup.cs로 제한을 해제한다.

Runtime.ps1은 기존 Hazards.ps1의 host/client가 Playing에 도달한 뒤 dot-source한다. 부모 작업에서 -MapPatchOnly 플래그와 `if($MapPatchOnly){. "$PSScriptRoot/../MapPatch~/Runtime.ps1";return}` 분기만 추가하면 기존 시작·종료·사용자 씬 복구를 재사용할 수 있다. 빌드는 네 맵의 자산을 적용한 동일 버전을 쓴다.

런타임 범위는 네 맵 로딩, 두 플레이어의 폭포 상승, Map02 자연 10/5초 주기와 두 효과의 동일한 시작·종료, 핀 절단 후 낙하, 경계 피해, 실제 사망 이후 다음 맵·새 플레이어와 핀 복구다. 접속자의 폭포 효과 픽셀은 검사하지 않는다. 경계 접촉 준비는 텔레포트, 핀 절단은 피해 API 직접 호출이며 실제 투사체 조준 검사는 추가하지 않는다.
