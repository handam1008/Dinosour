# 메뉴 확인 기록

2026-09-27. Unity CLI로 실제 MainMenu의 버튼을 클릭해 확인했다.

프로필은 기존 PlayerJobStorage와 JobCatalog를 읽고, 확정 장착 이벤트로 직업 이름과 모자를 갱신한다. 이름과 점수는 기존 PlayerInfoPanel 참조를 유지한다. 모자는 기존 MenuDinosaurPreview의 배치와 대기 프레임을 사용한다. 배경, 직업 색상, 진입 페이드, 장착 시 크기 변화만 표현에 추가했다.

`Logs/MenuJob27/Run-20260927014430/Result.json`에서 여섯 직업의 장착·메뉴 복귀·모자 영역·이름/점수 보존·선택 취소·씬 다시 열기·저장값 없는 기본 직업을 확인했다. 네 프레임 순환과 3픽셀 이상의 대기 움직임 검사도 통과했다. 기존 사용자 장착 직업인 암살자는 검사 후 복원했다. 새 팀 커스터마이징 메뉴의 진입·성별 탭·뒤로가기 연결은 유지했다.

방 참가 화면은 제목, 새로고침, 코드 입력, 비밀번호, 참가 버튼의 좌우 기준과 높이를 맞췄다. 방 행의 이름·인원·참가 영역을 분리하고 내용 폭에 맞게 늘어나도록 했다. 목록 로딩 중에는 빈 방 문구를 숨긴다. 낮고 넓은 창에서 뒤로 버튼이 잘리던 문제는 메인 Canvas의 화면 맞춤 설정으로 보정했다.

`Logs/MenuLayout27/Final/Sizes.json`에서 1920×1080, 1280×720, 1024×768, 1280×540의 버튼과 상태 문구가 화면 안에 있음을 확인했다. `Rows.json`은 실제 새로고침·빈 코드 오류·뒤로가기와, 긴 이름 및 여덟 행의 임시 UI 데이터에 대한 스크롤·첫 행/마지막 행 클릭 검증이다. 임시 행은 종료 시 제거했고 실제 서버 참가로 간주하지 않는다. 실제 UGS 참가와 퇴장은 방 수명 검사에서 별도로 확인했다.
