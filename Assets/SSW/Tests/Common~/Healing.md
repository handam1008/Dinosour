# 회복 숫자

2026-09-26, 프로토콜 16.

Health.Heal에서 상한을 적용한 실제 회복량만 OnHealed로 전달한다. 서버는 같은 값을 NotServer RPC로 전달하고 양쪽이 기존 데미지 숫자 애니메이션에 초록색 +숫자를 표시한다. 일반 회복, 재생, 흡혈, 회복 장판과 포션이 사용하는 공통 경로다.

- HealChecks.cs 12개: 소수 회복, 초과 회복, 풀 체력, 잘못된 입력, 최대 체력 변경, 스냅샷, 비권한·사망 상태.
- Healing.ps1 6개: 호스트·접속자 각각 7.5 회복 1회, 초과 회복의 실제 22.5 표시, 풀 체력/최대 체력 변경 제외, 접속자 임의 회복 거절, 새 라운드 재생성 시 가짜 회복 없음.
- 호스트 캡처에서 초록색 +7.5 확인. 숨긴 접속자 실행창의 캡처는 검은 화면이므로 접속자 픽셀 검증으로 사용하지 않는다. 접속자는 수신 이벤트·실제 회복량·HP 복제를 검사했다.
- 개발 빌드 build_0d988cae6cf4 성공, 오류 0개. 코드 검토에서 서버 권한·중복 이벤트·재생성 문제 없음.
