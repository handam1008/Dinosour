# 모자 미리보기 정렬

2026-09-26, Unity 6000.5.2f1, Unity CLI 연결 에디터에서 확인했다.

## 원인과 수정

게임의 `Visual/HeadAnchor/HatRenderer`는 원본 스프라이트 pivot을 머리 장착점에 놓는다. 선택창과 VS의 기존 UI는 중앙 pivot과 고정 사각형을 사용해 대부분의 모자가 얼굴 쪽으로 내려왔다. 실제 회전값은 모두 0이었다.

`HatLayout`은 플레이어 프리팹에서 저장한 머리 기준점, 회전, 반전과 직업의 `WorldOffset`을 UI 몸체의 스프라이트 좌표로 변환한다. 원본 모자 pivot과 종횡비를 적용하고, 모자를 몸체 이미지 자식으로 두어 좌우 반전과 애니메이션이 함께 움직이게 했다. 직업별 `PreviewScale` 비율은 유지한다.

선택창은 몸체 영역 280×280, 미리보기 위치 y=-50으로 조정해 긴 모자가 설명과 겹치지 않는다. VS 양쪽 미리보기는 배율 0.38, 위치 y=-20으로 맞춰 긴 모자도 초상화 마스크 안에 들어간다. 증강 초상화의 별도 크기 덮어쓰기는 제거했다.

게임 플레이어 프리팹, `JobCatalog`, 팀원 에셋, 직업 수치는 수정하지 않았다. UI에는 포즈 값만 저장하며 플레이어 프리팹 참조를 추가하지 않는다. 향후 실제 머리 기준점이 바뀌면 Edit 모드의 저장된 MainMenu에서 `Sync.cs`를 실행해 네 미리보기에 반영한다.

## 검증

`Run.cs`가 `Checks.cs`를 에디터에서 컴파일해 실행한다. MainMenu Play 모드에서 실행한다.

- 최종 `Logs/Hat26/checks.json`: 442개 통과, 실행 및 정리 오류 0개.
- 6개 실제 슬롯 클릭, 장착 버튼 제출, 저장값 및 메뉴 재진입 확인.
- 1920×1080, 1366×768 Game View에서 전체 직업 모자의 기준점, 종횡비, 설명/버튼과의 간격 확인.
- 네 idle 프레임과 상하 움직임, 비정사각 몸체 영역 및 다른 pivot에서도 부착점 유지.
- 실제 `Vs.Show`와 `Vs.Close`로 여섯 직업 양쪽 반전, 동일 크기, 모자 전체 마스크 포함, 종료 확인.
- 실제 `DraftScreen.SetPlayer`로 여섯 직업의 선택자/관전자 초상화 확인.
- `menu-직업.png`, `vs-직업.png` 실제 Game View 캡처 확인.
- 기존 선택 직업 Witch와 Game View 인덱스 3 복원, 임시 해상도 제거.

첫 검사에서 발견한 VS 모자 잘림과 테스트 도구의 임시 해상도 제거 인덱스를 고친 뒤 다시 실행했다. 이전 결과는 `checks-before-mask-fix.json`으로 보존했다.

VS는 실제 화면 컴포넌트에 캐릭터 정보를 전달한 UI 검사다. 별도 클라이언트 프로세스, 두 PC UGS 대전, 새 Player 빌드는 실행하지 않았다. 네트워크 멈춤 현상 해결 여부와는 별개다.
