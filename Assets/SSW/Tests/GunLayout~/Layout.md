# 총구·탄약 위치

2026-09-26, Unity 6000.5.2f1. 기준 Base `75e6f8174d0d4eef3414646264535e9660a1a350`.

실제 게임용 `Assets/SSW/Resources/Network/Player.prefab`의 Gunner 리그가 원본 KDH_Player Variant의 새 위치를 사용하도록 갱신했다. FirePos 로컬 위치는 `(1, 0.2, 0)`, Tanchang은 `(-0.5, -0.5, 0)`이며 로컬 회전·스케일도 원본을 복사한다. 기존 9개 Ammo 자식의 위치와 충전 표시 참조는 유지했다. 원본 KDH 자산과 무기 능력치는 수정하지 않았다.

Base의 `71f86e2`에서 비워진 WeaponView._gun, GunCast._gunView, GunCast._effects 참조를 기존 GunView/GunFx로 복구했다. 이 참조 없이는 총 표시가 일반 무기 경로로 돌고 실제 발사도 실패한다. NetPlayer._guard도 같은 커밋에서 비워진 상태를 발견했으며, 전투 담당 확인 항목으로 분리했다. 이 위치 변경에서 방어 로직을 수정하지 않았다.

`Sync.cs`는 Unity CLI의 eval_file로 실행하는 좁은 동기화 스크립트다. 원본의 로컬 Transform과 위 세 참조만 적용하며 효과 프리팹 재생성이나 능력치 설정 변경을 하지 않는다. 기존 GunChecks의 오래된 `(1, 0.7)` 고정 기대값도 원본 참조를 읽도록 바꿨다.

`SuperUltraLegendScene` 실제 연습 플레이에서 `Run.cs` 실행: `Logs/GunLayout26/checks.json` 77개 통과, 런타임 오류 0.

- 소유 플레이어/비소유 프록시의 로컬 총구·탄약 위치·회전·스케일과 9개 Ammo 자식이 원본과 일치한다.
- 좌우 및 양쪽 위 대각선에서 화면의 FirePos와 발사 위치 계산이 일치한다. 실제 발사한 네 발의 네트워크 탄환 생성 위치가 총구에서 시작하고 한 발씩 소모되며 표시 수가 일치한다. 방향 네트워크 양자화로 대각선 생성점 차이는 0.03 유닛 이내다.
- 실제 시간 경과로 재충전한 탄약 표시와 연습 리스폰 후 총구/탄약 참조·충전 동작을 확인했다.
- `Logs/GunLayout26/layout.png`의 실제 Game View를 확인했다.

검증은 같은 에디터의 호스트와 비소유 프록시 범위다. 별도 접속자 프로세스·두 PC UGS 세션·실제 대전 라운드 전환은 실행하지 않았다. 네트워크 권한, 피해·장탄수·재장전 수치는 이 변경에서 바꾸지 않았다.
